# About this repository

This repository is the documentation and examples for the
[flashscore-basketball-scraper](https://apify.com/clearfetch/flashscore-basketball-scraper) Actor. The Actor's source is not published here.

`sample-output.json` is a real row from a real run, not a mock-up.

Found a bug, or need a field that is not in the output? Open an issue here, or use the Issues tab on the Actor
itself. Both reach me.
